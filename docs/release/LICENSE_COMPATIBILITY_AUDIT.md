## Verdict

```
MIT_COMPATIBLE
```

No copied third-party source, vendored library, or externally sourced asset was found in the tracked tree. Dependency licences are not repository licences: the MIT licence granted over this repository's own code does not relicense PyTorch (BSD-style), scikit-learn (BSD-3), numpy (BSD-3), pandas (BSD-3), scipy (BSD-3), matplotlib (PSF-based), MedMNIST or WILDS. Users installing those dependencies accept their own terms. No dependency is redistributed here, so no third-party notice file is required under Apache-2.0 §4(d) or equivalent.

| Item | Assessment |
| --- | --- |
| Mathematical or algorithmic similarity to published methods | Not a licensing question. The repository reimplements standard procedures (random Fourier features, ridge-regularised discriminant analysis, Dirichlet client partitioning, blocked permutation tests) from published descriptions rather than copying code. | Whether any *untracked* local file (not part of the release) contains third-party source | Out of scope for a repository licence: untracked scratch files are not redistributed. Only tracked content is licensed. |
| Dataset terms (e.g. RxRx1, iWildCam, Camelyon17) | Governed by the dataset custodians. The repository redistributes no dataset content, so no dataset licence is implicated by this release. |

**Conclusion.** With no copied third-party source, no vendored library, no redistributed dataset, no redistributed pretrained weights and no third-party licence marker anywhere in the tracked tree, the MIT licence is compatible with this repository. Human review is not required for licensing compatibility.
